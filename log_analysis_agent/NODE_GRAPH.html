Log Analysis Agent Node Graph

当前代码的完整执行路径。每个节点下方列出它收到的状态、是否向 Ollama 发送 Prompt、返回内容以及下一跳。

flowchart TD
    START([START]) --> intake[intake<br/>初始化问题与状态]
    intake --> route_skill[Node 1: route_skill<br/>选择 Skill<br/>jenkins_api / copilot_sdk]
    route_skill --> validate_route[validate_route<br/>校验 Skill 与置信度]

    validate_route -->|有效| load_and_plan_skill[Node 2: load_and_plan_skill<br/>读取 SKILL.md 并生成计划]
    validate_route -->|错误 / unsupported / 低置信度| error_reply[error_reply]

    load_and_plan_skill --> validate_plan[validate_plan<br/>校验动作与命令]

    validate_plan -->|run_command| execute_command[Node 3: execute_command<br/>执行 Skill Python 命令]
    validate_plan -->|final_answer| final_reply[final_reply]
    validate_plan -->|ask_user| ask_user_reply[ask_user_reply]
    validate_plan -->|reroute_skill| prepare_reroute[prepare_reroute<br/>保存剩余目标并增加切换次数]
    validate_plan -->|无效计划 / 超过限制| error_reply

    execute_command --> review_result[Node 4: review_result<br/>评估命令结果]

    review_result -->|continue_current_skill| load_and_plan_skill
    review_result -->|reroute_skill| prepare_reroute
    review_result -->|complete| final_reply
    review_result -->|ask_user| ask_user_reply
    review_result -->|命令或评估失败| error_reply

    prepare_reroute -->|切换次数未超限| route_skill
    prepare_reroute -->|超过 4 次| error_reply

    final_reply --> END([END])
    ask_user_reply --> END
    error_reply --> END
