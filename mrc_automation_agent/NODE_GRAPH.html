一次完整扫描的节点输入与输出

示例输入为手动扫描 2026WW38。LangGraph 将完整 State 传入节点，节点只返回需要合并的状态增量。每个业务节点发出 progress 事件，由 Web 通过 SSE 展示。

步骤 1 · START → prepare_cycle

确定性校验节点

节点输入

{
  "cycle_code": "2026WW38",
  "reminder_type": "reminder",
  "triggered_by": "manual"
}

处理

  • 周期转为大写并去除首尾空格。
  • 校验格式为 YYYYWW01 至 YYYYWW53。
  • 校验操作类型为 reminder、lastreminder 或 ppt。

节点输出

{
  "cycle_code": "2026WW38",
  "reminder_type": "reminder",
  "triggered_by": "manual",
  "error": ""
}

下一跳

create_scan；校验失败进入 fail_scan。

步骤 2 · create_scan

MySQL 写入节点

节点输入

{
  "cycle_code": "2026WW38",
  "triggered_by": "manual",
  "error": ""
}

数据库操作

common.database.MySqlDatabase.connection()
INSERT mrc_reporting_cycles ... ON DUPLICATE KEY UPDATE ...
INSERT mrc_scan_runs (cycle_code, status, triggered_by)
VALUES ('2026WW38', 'running', 'manual')

节点输出

{"scan_run_id": 42}

下一跳

fetch_sharepoint；数据库异常进入 fail_scan。

步骤 3 · fetch_sharepoint

SharePoint I/O 节点

节点输入

{"cycle_code":"2026WW38","scan_run_id":42}

处理

  • 从独立 MRC .env 读取站点、证书和目录模板。
  • 将 {cycle_code} 替换为 2026WW38。
  • 忽略临时文件，只下载目录中的 .xlsx。

节点输出

{
  "workbooks": ["<WorkbookFile 1>", "<WorkbookFile 2>"],
  "files_found": 2
}

下一跳

parse_workbooks；无 Excel 或请求失败进入 fail_scan。

步骤 4 · parse_workbooks

Excel 解析节点

节点输入

{
  "workbooks": ["<WorkbookFile 1>", "<WorkbookFile 2>"],
  "files_found": 2
}

处理

  • 只读取每个工作簿的第一个 Sheet。
  • 在配置的前 N 行按表头定位，不依赖固定列字母。
  • 识别 Owner、Status Comments、动态 Platform:/Project: 和 COR-SP 的目标 WW 列。
  • Owner 当前可保存人名；以后值变成邮箱会自动写入 owner_email。
  • 按邮箱、团队、项目合并重复记录，优先保留非空状态。

节点输出

{"records":["<ProjectRecord ...>"]}

下一跳

select_recipients；格式或读取失败进入 fail_scan。

步骤 5 · select_recipients

确定性规则节点

节点输入

{
  "reminder_type": "reminder",
  "records": ["<ProjectRecord ...>"]
}

筛选规则

  • reminder：保留全部解析记录并生成全员草稿。
  • lastreminder：只保留至少一个项目缺少 Comments 的邮箱及该邮箱的项目。
  • ppt：不选择邮件收件人，也不生成邮件草稿。
  • 没有邮箱的记录仍会进入扫描快照，但不会成为邮件收件人。

节点输出

{"eligible_records":["<ProjectRecord ...>"]}

下一跳

build_drafts。

步骤 6 · build_drafts

邮件渲染节点

节点输入

{
  "cycle_code": "2026WW38",
  "scan_run_id": 42,
  "reminder_type": "reminder",
  "eligible_records": ["<ProjectRecord ...>"]
}

处理

  • 按规范化邮箱分组，一位负责人一封邮件。
  • 读取 templates/status_reminder_email.html 并替换模板变量。
  • 生成 Subject、HTML Body、项目数和幂等键。

节点输出

{
  "drafts": [{
    "owner_email": "owner@example.com",
    "subject": "Action required: update project status for 2026WW38",
    "project_count": 2,
    "idempotency_key": "2026WW38:42:reminder:owner@example.com"
  }]
}

当前节点只生成草稿，不调用邮件服务，也不会发送邮件。

下一跳

generate_ppt；模板读取失败进入 fail_scan。

步骤 8 · generate_ppt

独立 Copilot 节点

处理

  • 非 ppt 操作直接跳过，不调用 Copilot。
  • ppt 操作对本周期保存的每个 Excel 分别生成一份 PPT，并且不生成邮件草稿。
  • Copilot 检查工作簿的 sheet 列表并识别执行状态数据，不依赖固定文件名、sheet 名、表头行或列位置。
  • 使用代码中固定的 templates/DMR Johnson City SXT Executive Summary V2.pptx 模板。
  • 通过公共 common.skills.copilot_sdk 客户端调用 MRC_PPT_MODEL。

节点输出

{
  "artifacts": ["<Excel artifacts>", "<one PPT per Excel>"]
}

下一跳

persist_snapshot；生成失败进入 fail_scan。

步骤 9 · persist_snapshot

MySQL 事务节点

节点输入

{
  "scan_run_id": 42,
  "cycle_code": "2026WW38",
  "records": ["<ProjectRecord ...>"],
  "drafts": ["<EmailDraft ...>"],
  "files_found": 2
}

数据库操作

  • 通过公共 MySqlDatabase 获取连接。
  • 批量写入 mrc_scan_items。
  • 批量写入状态为 draft 的 mrc_email_deliveries。
  • 更新 mrc_scan_runs 为 succeeded 及统计字段。
  • 更新 Reporting Cycle 的 latest scan。
  • 全部操作在同一事务中提交，异常时回滚。

节点输出

{}

下一跳

END。MrcService 随后向 Web 发送 completed SSE 事件。

失败路径 · fail_scan

统一失败收尾节点

节点输入

{
  "scan_run_id": 42,
  "error": "SharePoint scan failed: ..."
}

处理

  • 如果扫描记录已经创建，将其更新为 failed。
  • 保存完成时间和截断后的错误信息。
  • 如果失败发生在 create_scan 之前，则没有数据库记录需要更新。

节点输出

{"error":"SharePoint scan failed: ..."}

下一跳

END。MrcService 向 Web 发送 error SSE 事件。

Web 与自动化开关

LangGraph 外部控制

手动扫描

Web POST /api/agents/mrc-automation/scans
  → MrcService 后台任务
  → graph.invoke(...)
  → progress / completed / error SSE

周期缓存

Web GET /api/agents/mrc-automation/cycles/{cycle_code}/latest
  → MrcDatabase.get_latest_scan(...)
  → 直接读取 MySQL，不运行 LangGraph

独立邮件操作

Web POST /api/agents/mrc-automation/cycles/{cycle_code}/mail
          → 从最近扫描快照读取草稿
          → All 或 Not Updated 收件人筛选
          → SMTP AUTH + STARTTLS
          → 记录 sending / sent / failed

独立 PPT 操作

Web POST /api/agents/mrc-automation/cycles/{cycle_code}/ppt
          → 只读取 workspace 中的当周 Excel
          → 本地无 Excel 时提示先 Scan SharePoint
          → Copilot + 固定模板生成可下载 PPT

Enable Automation

Web PUT /api/agents/mrc-automation/automation
  → MySQL mrc_automation_settings.enabled

当前 Enable Automation 只持久化开关，并在前后端禁用手动操作；后台 Scheduler 和自动判断 WW 尚未实现。手动 Send Mail 已接入 SMTP AUTH。
